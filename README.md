# 📊 Анализ востребованности навыков и зарплат в Data Science (Glassdoor)

## 📌 Описание проекта
В этом исследовании было проанализировано 1000+ вакансий с рынка труда, чтобы выяснить, какие навыки самые востребованные и где больше платят. Проект охватывает полный цикл разведочного анализа данных (EDA) — от очистки «сырого» датасета до извлечения скрытых инсайтов и визуализации зависимостей.

---

## 🛠️ Что было сделано (Используемые технологии):
* **Очистка данных (Python, Pandas):** Очищены сырые данные по локациям (выделены чистые штаты), удален технический мусор из названий компаний, а столбец зарплат приведен к числовому виду для расчета минимума, максимума и среднего значения.
* **Feature Engineering:** Написаны скрипты для поиска ключевых навыков (**Python, SQL, Excel, Tableau, Spark**) внутри текстов вакансий и создания соответствующих флагов.
* **Аналитика и статистика (SciPy/NumPy):** Посчитана корреляция между рейтингом компаний и уровнем зарплат.
* **Визуализация (Matplotlib & Seaborn):** Построены графики распределения зарплат, хит-парад регионов и тепловая карта корреляции признаков.
---

## 📊 Главные выводы исследования:
1. **Лидер по спросу:** Python требуется в 45% всех вакансий.
2. **Где больше платят:** Самая высокая средняя зарплата зафиксирована в штате Калифорния ($142K).
3. **Инсайт:** Рейтинг компании практически никак не влияет на уровень предлагаемой зарплаты (корреляция близка к 0).
