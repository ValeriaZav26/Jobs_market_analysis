# Jobs_market_analysis

# Анализ востребованности навыков и зарплат в Data Science

Краткое описание проекта: в этом исследовании я проанализировал 1000+ вакансий с рынка труда, чтобы выяснить, какие навыки самые востребованные и где больше платят.

## 🛠️ Что было сделано:
* Очищены сырые данные по локациям (выделены чистые штаты).
* Написаны скрипты для поиска ключевых навыков (Python, SQL, Excel) внутри текстов вакансий.
* Посчитана корреляция между рейтингом компаний и уровнем зарплат.

## 📊 Главные выводы исследования:
1. **Лидер по спросу:** Python требуется в 45% всех вакансий.
2. **Где больше платят:** Самая высокая средняя зарплата зафиксирована в штате Калифорния ($142K).
3. **Инсайт:** Рейтинг компании практически никак не влияет на уровень предлагаемой зарплаты (корреляция близка к 0).
